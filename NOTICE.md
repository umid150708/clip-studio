## Sound recordings (energetic-stream-edit)
The sound kit in `skills/energetic-stream-edit/assets/sfx_kit/` is cut from recordings in the **SSE Library** on the Internet Archive (https://archive.org/details/SSE_Library_EXPLOSIONS and the other SSE Library items named in `download_plan.json`). The USC Optical Sound Effects Library and Sunset Editorial collection made the recordings, Craig Smith provided the tapes, and Jason Scott uploaded them. Each item's metadata states CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). Every kit clip's source file, URL and licence are in `kit.json`. No other sound is included.

## Fonts and emoji (energetic-stream-edit)
Captions and emoji use fonts that ship with macOS (Arial Rounded, Avenir Next, Apple Color Emoji). No font files are distributed here.

## Tools the scripts call
`yt-dlp` (Unlicense), `ffmpeg` (LGPL/GPL, depending on build), OpenCV (Apache-2.0), Pillow (HPND), NumPy (BSD), and Apple's Vision framework on macOS. Each keeps its own licence. `energetic-stream-edit` uses Python's standard library and the same ffmpeg, OpenCV, Pillow and NumPy.

## Examples and names
No example uses a real person's likeness or a real channel's assets. Any names that appear in the documentation are generic placeholders.
